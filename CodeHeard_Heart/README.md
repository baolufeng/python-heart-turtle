# 心迹 · Echo of Light

一颗由代码生成、可以被看见、听见，也能读懂手势的爱心。

作品以参数方程生成心形轮廓，默认展示带环绕光环和蕾丝光幕底座的粉色星环浮光心，并提供星环浮光心、流光丝线心、粉雾粒子心三种动态 3D 形态。爱心会持续进行带透视和倾斜变化的旋转；页面不设置形态或配色按钮，所有颜色与形态变化均通过摄像头手势完成。食指负责循环切换以粉色为起点的多种配色，握拳、比 V、张开手掌分别负责切换三种形态。

## 运行方法

Windows 用户双击 `启动作品.bat`，浏览器会自动打开作品并启动本地服务。启动脚本会从 8765 开始自动查找可用端口，因此旧进程占用端口时也不会阻止页面打开。页面进入后，右下角会自动出现手势识别面板并请求摄像头权限。使用摄像头时必须通过此方式启动，因为浏览器只允许 `localhost` 页面访问摄像头。

也可以右键使用 PowerShell 运行 `serve.ps1`。普通视觉与声音效果无需联网；在较新的 Chrome 或 Edge 中打开，按提示允许摄像头权限即可使用手势识别。

不使用摄像头时，也可以直接打开 `index.html` 浏览普通动画，但浏览器会因本地文件安全策略限制手势模型加载。

## 摄像头打不开时

1. 在 Codex 文件列表中点击 `启动作品.bat` 只会打开源码，不会运行程序。必须打开 Windows 文件资源管理器，在作品文件夹中双击它。
2. 浏览器首次询问摄像头权限时选择“允许”。
3. 如果之前点过拒绝，点击右下角面板中的“重试摄像头”。
4. 如果提示“没有检测到可用摄像头”，检查摄像头连接和 Windows 设置 → 隐私 → 摄像头，确认允许桌面应用访问摄像头。
5. 如果提示“摄像头正被其他程序占用”，先关闭正在使用摄像头的会议或相机程序。

## 操作说明

- 点击爱心或“让心动”：触发心跳涟漪、粒子绽放与心语。
- 页面进入后右下角自动启动摄像头与本地手势模型；如首次拒绝权限，可点击“重试摄像头”。
- 右上角“关闭识别”或面板右上角“×”可停止摄像头；也可按 `C` 键切换。
- 伸出食指并保持约 1 秒：循环切换配色，默认与主视觉均为粉色；持续停留会继续循环，放下手指即停止。
- 握拳并保持约 1 秒：切换带环绕光环的“星环浮光心”。
- 比出 V 手势并保持约 1 秒：切换“流光丝线心”。
- 张开手掌并保持约 1 秒：切换偏密集、无环绕光环的“粉雾粒子心”。
- 右上角“声音”：开启或关闭 Web Audio 合成声景。
- 鼠标移动：心形粒子会轻轻避让指针。
- 键盘：`Space` 心跳，`M` 开关声音，`Esc` 关闭摄像头。

## 技术与实现

- 原生 HTML、CSS、JavaScript 页面，无需安装第三方运行库。
- WebGL 三维心形网格使用平滑顶点法线、方向光、镜面高光与边缘光；WebGL 不可用时自动降级为 Canvas 3D 分层渲染。
- Canvas 2D 星尘、前后面轨道、粒子和交互光效，配合心形参数方程、透视旋转与伪高斯两次心跳节拍。
- 响应式布局，适配桌面和手机；支持减少动态效果的系统设置。
- Web Audio API 实时合成和弦与心跳低音，不依赖音频文件。
- MediaPipe Hand Landmarker 在浏览器本地识别 21 个手部关键点，通过伸直手指数量判断手势。
- 识别结果必须稳定约 0.75 秒才执行，冷却 1.5 秒，避免误判和连续跳转。
- MediaPipe 的 JavaScript、WASM 和模型文件已放入 `vendor/mediapipe/`，无需现场下载。
- 摄像头画面只在浏览器内存中用于识别，不上传、不保存。
- 无图片素材、无框架、无网络字体，作品可在离线环境稳定运行。
