# “心迹 · Echo of Light”提交说明

## 作品思路

爱不只是一种图形，也可以是一种“被听见”的节律。作品以心形参数方程生成核心轮廓，默认展示带环绕光环和蕾丝光幕底座的粉色星环浮光心，并提供星环浮光心、流光丝线心、粉雾粒子心三种形态。爱心持续进行带透视和倾斜变化的三维旋转，用双脉冲函数模拟真实心跳，再以颜色、文字和声音回应触碰。页面底部不设置操作按钮，颜色与形态统一交给摄像头手势控制。

作品进一步加入摄像头手势交互：页面进入后右下角自动显示摄像头识别面板，画面在浏览器本地计算 21 个手部关键点。食指用于循环切换以粉色为起点的多种配色；握拳、V 手势和张开手掌分别对应三套粒子形态。识别结果稳定后才触发变化，避免误判。

## 主题契合

作品围绕“爱心”展开，心动、思念、陪伴与希望始终是画面的核心。交互后出现的心语和手势反馈保持温暖、积极、简洁，符合校园活动内容健康的要求。

## 运行环境

- Windows 10/11（摄像头模式建议使用 Windows 版 Chrome 或 Edge）
- 较新版本的 Chrome / Edge；普通动画也兼容 Firefox
- 运行所需的手势模型与 WASM 已放在本地目录，无需现场联网
- 摄像头功能需通过 `启动作品.bat` 在本机 localhost 页面运行
- 建议屏幕分辨率 1280 × 720 以上；同时适配手机竖屏

## 使用到的技术

1. WebGL 三维网格、平滑顶点法线、实时方向光与镜面高光。
2. 心形参数方程生成边界点，固定种子随机数生成内部粒子。
3. 双高斯脉冲函数表现“咚—咚”两次心跳。
4. Canvas 2D 前后景分层、透视投影与三条倾斜椭圆轨道实现立体环绕。
5. 指针距离检测与粒子避让，触摸时产生扩散涟漪。
6. Web Audio API 实时合成五声音阶和弦和环境低音。
7. MediaPipe Hand Landmarker 识别手部 21 个关键点，并按手指伸展状态分类手势。
8. WebGL 不可用时自动切换为 Canvas 分层立体渲染。
9. 识别防抖采用“稳定保持时间 + 切换冷却”机制。
10. CSS 自定义属性完成主题换色，媒体查询完成响应式布局。

## 原创与引用

页面结构、视觉系统、粒子运动、手势判定和交互方式为本次作品独立编写，未直接复制或修改现成完整作品。

本次创作在概念梳理、初稿代码、手势模型接入、细节调试和文档整理中使用 AI 辅助。AI 工作属于辅助性质；提交者需要理解代码的主要执行流程，能够说明心形坐标如何生成、粒子如何旋转、摄像头如何识别手势以及声音如何合成。

## 操作方式

- 双击 `启动作品.bat`；右下角会自动启动手势面板，首次使用请允许摄像头权限。
- 如果拒绝或关闭后想重新开启，可点击顶部的“手势识别”或右下角的“重试摄像头”。
- 点击“让心动”或爱心：触发心跳与粒子绽放。
- 伸出食指并保持约 1 秒：循环切换配色，主视觉默认为粉色；持续停留会继续循环，放下手指即停止。
- 握拳、比 V、张开手掌并保持约 1 秒：分别切换星环浮光心、流光丝线心、粉雾粒子心。
- 按 `C` 键切换摄像头识别；爱心默认自动旋转。
- 点击右上角“声音”：开关合成声景。
- 按空格键触发动效；按 `M` 开关声音；形态与配色通过摄像头手势切换。

## 可直接形成的答辩表述

“我先把爱心的数学轮廓转换成上千个粒子，再给每个粒子记录相位、速度、深度、颜色和层级。每一帧根据时间重新计算呼吸偏移、心跳缩放和三维透视变化。摄像头部分先在本地运行 MediaPipe 手部关键点模型，判断拇指和四根手指是否伸直：食指用于循环换色，握拳对应带光环的星环浮光心，V 手势对应流光丝线心，张开手掌对应粉雾粒子心。手势需稳定约 1 秒才切换，防止画面误判。声音由 Web Audio 振荡器实时合成，没有加载音频文件。”
